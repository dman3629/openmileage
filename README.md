# OpenMileage

OpenMileage is a free, private mileage log for gig workers, couriers, rideshare drivers and self-employed people. Enter a start and end odometer reading, keep a tax-ready log in your browser, and export it as CSV or a printable report whenever you need it.

- No account, app install or trip cap
- Shift and individual-trip logging
- IRS and HMRC standard mileage calculations
- CSV import and export
- Print-friendly reports
- Optional email-and-code cloud backup
- Local-first: mileage stays in `localStorage` unless you choose backup

Open `index.html` directly or serve this directory with any static web server. There is no build step.

## Privacy

OpenMileage uses no cookies. It records anonymous page-view and action counts. Personal information is sent only when you choose cloud backup.
